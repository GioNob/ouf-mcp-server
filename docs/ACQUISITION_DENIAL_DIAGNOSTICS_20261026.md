# Acquisition READ denial provenance

The deployed bd60ccd projection collapsed missing OAuth scope, missing grants, an undeclared capability in a local bundle and missing delegation into the same nonretryable `authorization denied`. This prevented diagnosis after real HUMAN publication of policy50; it does not prove which guard denied those historical calls.

The local service now preserves reasonCode and evaluated bundle version in a typed error while retaining errors.Is(ErrUnauthorized), the historical error string and the existing private audit. Only the two acquisition READ handlers expose a bounded caller-result projection: code, retryable=false, authorizationPhase=MCP_PRE_ADMISSION, an allowlisted reasonCode, and a positive evaluatedPolicyVersion when a policy was evaluated. Missing delegation reports no invented version. Unknown reason strings are reduced to AUTHORIZATION_DENIED. No identity, token, scope list, grants, resource attributes, bundle name, raw decisionRef, audit row or private error is exposed by this projection.

This is the caller's present denied result, not a capability to read protected audit or acquisitions, nor the full frozen AuthorizationDecision DTO. It never reserves admission, dispatches to Gateway, creates a retry, authenticates, grants authority or refreshes the cache. Generic tools keep the existing generic projection. Owner refusals after successful local admission remain owner results and are not labelled local denials.

Authorization PET1.5 §7 freezes ALLOW/DENY+reasonCode+policyVersion; §27 requires safe reasonCode logging without raw tokens/secrets. The original attached package e63df67e8817eec38a9d4b3eb736b020f693b932f3360dc02f4555330f2201ce was consulted, including authorization-decision-v1 and policy-evaluation-evidence-v1 scope controls. MCP PET1.4 and resilience v3 retain fail-closed boundaries and forbid automatic permanent-denial retries. This small projection does not assert full contract/PET compliance or alter owner permissions.

Tests cross the actual MCP SDK, local cached evaluator and TLS adapter for both tools: valid grant with missing scope, valid scope without grant, expired grant, explicit deny, old bundle lacking the descriptor, permitted read and owner403. They verify zero admission/dispatch on local denial and no principal/credential/bundle-name leakage. Typed-error wrapping, bounded unknown reasons, absent version for missing delegation and private-audit continuity are covered.

Repository tests are not live diagnosis. Production policy50, user scopes, loaded MCP bundle, Gateway/IAM and owner results are not synthetic test authorities. No target command, deployment, acquisition retry, IAM/role/grant change, SQL/private-audit read, Registry restart or acceptance is authorized/performed by this commit. The deployed image remains bd60ccd pending separately reviewed target work. OUF-deploy#50 retains the two actual denials and all consumed scopes.
